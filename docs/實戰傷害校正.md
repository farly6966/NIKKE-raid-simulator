# 實戰傷害校正（實驗功能）

實戰推演新增選用開關，預設關閉。關閉時維持原本流程：回填實際傷害後扣王血、扣刀、排除已用角色並重排，候選傷害使用原始模擬值。

開啟只啟用分析，不會自動採用係數。係數只是本盤試算假設，不能修復模擬引擎的機制錯誤。

## 操作

1. 開啟「實戰傷害校正」。
2. 回填遊戲結算數字。確認正常完整出刀、條件可比較時，勾選「已核對結算、正常完整出刀（含極限收尾；納入分析）」；預填值不會自動納入。
3. 系統依剩餘 HP 提示疑似收尾刀，未核對時會展開樣本檢查。極限收掉且正常完整出刀可選「正常完整出刀／極限收尾（納入）」；只有確認因王提早死亡而未打滿時，才選「已確認溢出尾刀（排除）」。也可排除失誤、斷線與條件不同的紀錄。舊紀錄缺少模擬快照時不納入。
4. 每隻王分開觀察。至少 5 刀、3 位成員，80% 同方向，80% 比例落在中位數正負 3 個百分點內，而且中位數偏離原始模擬至少 5%，才提供校正建議。
5. 點「預覽校正與重排」，檢查推進階段、排刀數、無限五王預估、成員分配變化及完整順序，再「確認套用校正」。預覽失敗或取消不影響現有方案。
6. 可撤銷單一王的校正。關閉開關會清除全部係數並以原始模擬重新排刀；再次開啟仍需重新預覽確認。

## 範圍與限制

- 建議係數為有效樣本的「實際傷害 ÷ 原始模擬傷害」中位數；不在 0.5～1.5 內時要求先核對條件，不提供比例套用。
- 各王的有效樣本跨階段彙整；使用者需自行確認可比較。係數套用到該王所有階段的剩餘候選隊伍，不能推論每個隊伍都具有相同誤差。
- 門檻是第一版啟發式規則，不是統計信賴區間或準確度保證。只有成員數與集中程度門檻，尚未自動辨別編成多樣性或戰鬥機制差異。
- 收尾提示依回填前剩餘 HP 判斷，不直接推論傷害溢出。即使不是系統辨識的收尾刀，也可人工標記為溢出尾刀，以處理 HP 或輸入精度的落差。所有分類都可修改；撤銷前面的刀不會改寫這筆紀錄的人工分類。
- 舊版曾自動排除的收尾紀錄升級後會回到待確認，不會直接當成有效樣本。極限收尾仍需由操作者確認是否具有可比較的完整輸出。
- 基準固定使用原始模擬，不連乘已套用係數。每筆新紀錄保留原始模擬、當時採用預估和實際傷害；修改係數不回寫歷史紀錄。
- 開關、採用係數與樣本標記跟隨本機盤面保存；匯入另一份試算或重置出刀時全部回到關閉。尚未提供實戰盤面分享或校正資料匯出。
- 預覽期間若新增／撤銷出刀、修改樣本資格、切換開關或匯入資料，舊預覽立即失效。
- 前後方案使用不同傷害假設；畫面上的預估提高不代表真實輸出提升。求解器未證明最優時會明確標示。

## 實作位置

- `site/src/union-raid-calibration.ts`：狀態驗證、趨勢判斷、從原始候選衍生係數結果。
- `site/src/union-raid-calibration-view.ts`：開關、提醒、樣本檢查、獨立 worker 預覽。
- `site/src/union-raid-live-view.ts`：本機保存、出刀快照與現有排刀流程整合。

本功能不修改 Python 傷害引擎、不重跑角色戰鬥模擬，只重新求解排刀。
