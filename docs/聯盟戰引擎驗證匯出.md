# 聯盟戰引擎驗證匯出

聯盟戰畫面完成試算後，按「匯出引擎驗證資料」，會下載 `聯盟戰引擎驗證_日期.json`。檔案保存每一盤的完整計算請求、總傷、命中數及逐角色傷害，供 Python 與新版引擎逐盤重播。

匯出資料以流水號表示成員，不包含成員名稱、openid 或帳號 cookie。**完整請求仍包含角色育成數值**，請保存在本機，只交給可信任的驗證者。原本的「匯出試算結果」按鈕與格式不變，仍供實戰推演使用。

2026-09-20 的舊試算結果只保存階段、隊伍與總傷，缺完整請求；需要重新設定當時的 Boss 和編隊並跑出新結果，才可做精確的逐盤比對。此匯出功能只記錄已完成的試算，不會更改公式或排刀。
